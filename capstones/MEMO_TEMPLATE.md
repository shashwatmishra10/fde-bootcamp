# Deployment memo — <project>
1. **Customer problem** (who, what pain, cost of the pain)
2. **Current systems** (what exists today, data sources, constraints)
3. **Constraints** (security, compliance, network, budget, people)
4. **Architecture** (diagram + components + data flow)
5. **Rollout plan** (pilot → expand; owners; timeline)
6. **Success metrics** (adoption, accuracy, time saved, cost)
7. **Risks & mitigations**
8. **What should become core product** (vs one-off customisation)
